# 시험 응시 현황 엑셀 자동 집계기

Python, Streamlit, openpyxl로 만든 한국어 업무 자동화 웹앱입니다. 사용자가 업로드한 `.xlsx`의 실제 셀 값을 읽어 지역별 시험 응시 현황을 집계하고, 두 가지 독립 방식으로 검산한 뒤 새 XLSX 보고서와 UTF-8 BOM CSV를 생성합니다.

원본 워크북은 수정하거나 다시 저장하지 않습니다. 모든 입출력은 `bytes`와 `BytesIO`를 이용해 메모리에서 처리합니다.

## 주요 기능

- `지역전체`, `직전시험`, 숫자 4자리 시트를 자동 탐색
- 후보마다 행 수, 이름·시험현황 유무, 헤더 상태와 제외 사유 표시
- 최신으로 보이는 숫자 4자리 시트를 추천하되 사용자가 직접 선택
- A열 지역, D열 이름/이름구분, I열 시험현황을 실제 값으로 집계
- 숨겨진 행과 필터 범위 행 포함
- 예상하지 못한 상태값을 자동 보정하지 않고 별도 보고
- 행 순회 방식과 조건별 카운트 방식의 독립 검산
- 7개 시트 XLSX 보고서와 UTF-8 BOM CSV 다운로드
- 전체 traceback과 개인정보를 일반 화면·개발자 로그에 노출하지 않는 오류 처리
- 데스크톱 4열 KPI, 모바일 단일 열 반응형 UI

## 입력 워크북 규칙

### 후보 시트

다음 이름 중 하나와 정확히 일치해야 합니다.

- `지역전체`
- `직전시험`
- 정규식 `^\d{4}$`를 만족하는 이름(예: `0719`, `1207`)

`지역전체 사본`, `직전시험 사본`, `0719사본`처럼 문자가 덧붙은 시트는 자동 후보가 아닙니다. 이름 규칙을 만족해도 필수 열을 읽을 수 없거나 이름이 있는 데이터 행이 없으면 분석 불가로 표시합니다.

### 헤더와 데이터 범위

- 기본 헤더 행: 1행 (`sheet_detector.py`의 `HEADER_ROW`)
- A열: `지역`
- D열: `이름`, `성명`, `이름구분` 중 하나
- I열: `시험현황`, `시험 현황` 중 하나
- 데이터 시작: 헤더 다음 행
- 마지막 데이터: 워크시트의 실제 `max_row`

열 위치가 존재하고 헤더 텍스트만 다르면 경고 후 분석할 수 있습니다. 헤더가 공란이거나 필수 열 위치 자체를 읽을 수 없으면 분석을 중단합니다. 업로드 시 실제 구조 차이는 후보 표, 헤더 확인 표, 특이사항 및 생성 보고서의 `헤더확인` 시트에 기록됩니다.

워크북은 아래 방식으로 열며 수식은 저장된 계산값을 읽습니다.

```python
load_workbook(
    filename=BytesIO(file_bytes),
    data_only=True,
    read_only=False,
)
```

수식은 있으나 저장된 계산값이 없으면 해당 값은 공란으로 읽히며 화면과 `특이사항` 시트에 경고합니다.

## 행과 문자열 처리

- 헤더 행, 완전히 빈 행, D열 이름이 공란인 행은 제외합니다.
- D열이 숫자·날짜·기타 값이어도 공란이 아니면 이름이 있는 행입니다.
- 문자열은 `str(value).strip()`으로 앞뒤 공백만 제거합니다.
- 내부 공백, 철자, 괄호는 바꾸지 않습니다. `정규응시`, `정규 응시`, `정규응시 완료`는 서로 다른 값입니다.
- 위 행의 지역값, 병합 셀의 윗값, 비슷해 보이는 문자열을 아래 행에 채우거나 통합하지 않습니다.
- 숨겨진 행과 자동 필터 범위의 행도 실제 값이 있으면 포함합니다.

## 지역 처리

A열 값을 문자열로 바꾸고 앞뒤 공백만 제거해 지역으로 사용합니다. 실제로 발견된 순서를 유지하며 같은 문자열만 하나의 지역으로 합칩니다.

- 지역 공란: 제외행에 기록하고 모든 지역별 합계에서 제외
- `대학`: 결과 행은 유지하지만 모든 수치 셀을 실제 빈 셀로 생성
- `대학`: 자동 집계, 전체 합계, 미응시 합계, 예상 밖 상태 합계에서 제외
- 지역명을 임의로 통합·수정하지 않음

`대학`의 값은 별도 원본 시트에서 수기로 관리한다는 안내 메모가 결과 워크북에 포함됩니다.

## 시험 유형별 집계

정확히 다음 값만 자동 집계합니다.

| 출력 항목 | I열의 허용 상태값 |
|---|---|
| 정규응시 | `정규응시` + `정규응시(타지파)` |
| 대면응시 | `대면응시` |
| 일대일응시 | `일대일응시` |
| 서면응시 | `서면응시` |
| 비공식응시 | `비공식응시` |

전체응시는 다음 다섯 출력 항목의 합입니다.

```text
전체응시 = 정규응시 + 대면응시 + 일대일응시 + 서면응시 + 비공식응시
```

대면응시는 정규응시와 별도 항목입니다. 각 행은 정확히 한 상태에만 집계됩니다.

`전체 응시목표`와 `전도 재적대비 %`는 자동 계산하지 않으며, 모든 지역과 합계에서 숫자 0이나 하이픈이 아닌 실제 빈 셀로 유지합니다.

## 미응시자 계산

```text
최종 미응시자 = I열이 정확히 `미응시`인 행 + 이름은 있으나 I열이 공란인 행
```

두 조건은 겹치지 않으며 화면과 보고서에서 `명시적 미응시`, `시험현황 공란`, `최종 미응시자`를 따로 제공합니다. 예상하지 못한 상태값은 미응시자로 자동 처리하지 않습니다.

## 예상하지 못한 값

허용 목록 밖의 비공란 상태값은 모든 응시 유형과 미응시 합계에서 제외합니다. 화면에는 원본 값, 앞뒤 공백만 제거한 값, 건수, 지역별 건수, 압축 행번호를 표시하고 상세 펼쳐보기에서 시트명·행번호·지역·이름·원본 상태를 확인할 수 있습니다.

## 두 가지 독립 검산

1. 각 행을 한 번 순회하며 지역과 상태를 판정
2. 지역·상태 조건마다 대상 행을 다시 필터링해 카운트

지역별 원시 상태, 파생 정규응시, 전체응시, 명시적 미응시, 상태 공란, 최종 미응시자, 예상 밖 상태와 전체 합계를 비교합니다. 하나라도 다르면 XLSX/CSV를 만들지 않고 차이 지역, 항목, 방식 1 값, 방식 2 값을 표시합니다.

## 결과 XLSX

파일명은 `시험응시현황_집계결과_{선택시트명}_{YYYYMMDD_HHMM}.xlsx` 형식입니다.

1. `집계결과`: 지역별 10개 고정 컬럼, 대학 공란 행, 합계
2. `전체합계`: 응시·미응시·예외·제외 건수 세로 요약
3. `상태값검산`: 지역별 원시 상태와 파생값
4. `헤더확인`: 기대값, 실제값, 판정, 설명
5. `특이사항`: 공란, 예상 밖 값, 숨김·필터, 후보 제외 등
6. `제외행`: 행번호, 지역, 이름, 상태, 제외 사유
7. `분석정보`: 분석 시각과 구조 정보(개별 이름이나 원본 전체 데이터 미복사)

결과 시트는 제목 띠, 헤더 색상, 숫자 서식, 틀 고정, 자동 필터, 조정된 열 너비를 적용합니다.

CSV 파일명은 `시험응시현황_집계결과_{선택시트명}.csv`이며 `집계결과`와 같은 컬럼과 합계 행을 포함합니다. 인코딩은 Excel 한글 호환을 위한 UTF-8 BOM입니다.

## 로컬 실행

Python 3.10 이상을 권장합니다.

```bash
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\activate
```

macOS/Linux:

```bash
source .venv/bin/activate
```

설치와 실행:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

브라우저에서 표시된 로컬 URL을 열고 `.xlsx`를 업로드합니다.

## 테스트

테스트 데이터는 `tests/conftest.py`가 메모리에서 생성하는 익명 XLSX만 사용합니다. 실제 사용자 파일이나 개인정보는 저장소에 포함하지 않습니다.

```bash
python -m compileall .
python -m pytest -q
```

현재 프로젝트는 후보 탐색, 정확 일치 집계, 대학 공란, 숨김·필터 포함, 수식 캐시 경고, 독립 검산, 7개 결과 시트, CSV BOM, 원본 바이트 불변과 전체 종단 흐름을 포함한 86개 테스트 사례를 제공합니다.
